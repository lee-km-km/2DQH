🚀 연구원을 위한 3단계 핵심 이용 가이드

STEP 01
🔬

장비 상태 확인 & QR 스캔

연구장비 포털에서 각 연구장비의 실시간 가동 상태(대기중/가동중)를 확인하거나, 장비 본체에 부착된 QR 코드를 스마트폰으로 스캔합니다.

➔
STEP 02
📝

시운전 파라미터 작성

[장비 사용 기록 작성]을 클릭하고 시료명, 측정 목적, 장비별 고유 물리 파라미터(칠러 온도, 진공도, 레이저 파장, 하중 등)를 입력합니다.

➔
STEP 03
📊

전자로그북 보존 & 캘린더 조회

작성 즉시 Supabase 전용 테이블에 저장되며, 월간 캘린더 일자를 클릭하여 해당 날짜의 측정 내역과 연구원별 세션을 즉시 열람합니다.

  • 월간 가동 캘린더: 이전달/다음달 이동 및 날짜 배지 클릭 시 해당 일자의 사용자명, 시료명, 측정 시간 상세 조회

❓ 연구원 자주 묻는 질문 (FAQ)

항목을 클릭하면 상세 설명이 펼쳐집니다

연구장비 포털 화면에서 원하는 장비 카드를 클릭하면 장비 상세 정보와 상태(가동중/대기중)를 확인할 수 있습니다.

장비 본체에 부착된 QR 코드를 스마트폰 카메라로 스캔하거나, 화면의 [📝 장비 사용 기록 작성] 버튼을 클릭하면 시료명, 측정 목적, 장비 고유 파라미터(칠러 온도, 진공도, 파워, 빔 스팟 등)를 입력할 수 있는 전자로그북 모달이 열립니다. 기록 저장 즉시 클라우드 데이터베이스에 보존됩니다.

국가연구개발과제 감사 및 연구 데이터의 무결성과 감사 추적성을 위해 일반 연구원 모드에서는 임의 삭제가 제한되어 있습니다.

입력 내용의 수정이나 취소가 필요한 경우 실험실 관리자(또는 책임자)에게 요청하시면, 관리자 로그인 상태에서 해당 기록 우측의 [🗑️ 삭제] 버튼을 통해 데이터베이스에서 안전하게 수정하거나 삭제할 수 있습니다.

좌측 사이드바의 [특별관리물질] 메뉴로 진입하면 N센터 86291호 연구실 보유 시약 목록이 표시됩니다.

사용 전/후 본인이 취급한 시약 행의 [📝 취급일지 작성] 버튼을 누르고 사용량(g 또는 mL)을 입력하면, 현재 재고량에서 사용량이 실시간 자동 차감되어 남은 잔여량이 계산됩니다. 필수 개인보호구(방독마스크, 보안경, 내화학장갑) 착용을 체크하고 등록하면 산업안전보건법 제439조에 따라 30년간 보존됩니다.

1. 시약별 개별 이력 조회: 재고 목록 테이블 우측의 [이력] 버튼을 클릭하면 해당 물질의 최초 입고량부터 역대 사용자별 사용량과 잔여량 변동 그래프가 팝업으로 투명하게 공개됩니다.

2. 취급 일지 캘린더: 상단 탭에서 [📅 취급 일지 캘린더]를 누르면 달력 날짜별로 어떤 연구원이 무슨 시약을 몇 g/mL 사용했는지 컬러 배지로 표시되며, 일자를 클릭하여 당일 상세 내역을 즉시 확인할 수 있습니다.

고용노동부 및 연구실안전관리원 법정 감사 서식 출력은 관리자 로그인 상태에서만 버튼이 노출됩니다.

• 특별관리물질 고지문: 시약 체크박스를 선택하고 [특별관리물질고지]를 누르면 '관계자 외 출입금지', 붉은색 물질명, 발암성/생식세포 변이원성/생식독성 표가 기재된 표준 A4 고지문이 팝업되며 즉시 인쇄/PDF 저장이 가능합니다.

• 특별관리물질 취급일지: [특별관리물질취급일지]를 누르면 N센터 86291호 연구실 공식 규격의 엑셀 CSV가 즉시 다운로드됩니다.

좌측 메뉴 [비품 대여 및 반납]에서 원하는 비품의 [⚡ 대여 신청]을 클릭하고 성명과 연구실, 반납 예정일을 선택하면 1인 최대 3점까지 즉시 대여 승인됩니다.

사용 완료 후 [반납] 버튼을 누르면 해당 비품이 원래 비치되어 있어야 할 실험실 보관 캐비닛 및 선반 위치(Shelf)가 자동으로 팝업 안내되어 분실을 방지합니다.

스마트폰 기본 카메라 앱으로 장비 본체나 시약장 라벨의 QR 코드를 비추면 별도의 앱 설치나 로그인 절차 없이 해당 장비의 전자 로그북 작성 화면 또는 시약 취급일지 작성 화면으로 즉시 연결됩니다.

측정 시작 직전 또는 시약 사용 직후 현장에서 즉시 등록할 수 있어 수기 기록 누락을 방지하고 현장에서 간편하게 등록할 수 있습니다.

• 일반 연구원 (비로그인): 연구장비 카탈로그 및 실시간 가동 상태 조회, 가동 세션 파라미터 작성, 시약 재고 및 사용 이력 열람, 본인 취급일지 등록, 공용 비품 간편 대여/반납이 가능합니다.

• 관리자 (Admin): 잘못 등록된 가동 기록 및 취급일지 정정·삭제, 법정 감사용 엑셀 및 A4 고지문 PDF 생성, 시약/장비 신규 등록 및 수정, Supabase 클라우드 데이터베이스 직접 조작, 관리자 전용 운영 매뉴얼 열람이 가능합니다.

관리자 모드 활성화됨 (최고 권한)

모든 세션 데이터 삭제, 연구실 안전 점검 대비 법정 서식 및 데이터 엑셀 출력, 고지문 PDF 생성, 장비별 전용 테이블을 직접 확인하고 관리할 수 있습니다.

🗑️ 1. 장비 사용 기록 및 취급일지 데이터 정정·삭제

• 장비 가동 세션 삭제: 장비 상세 페이지의 최근 가동 기록 또는 가동 피드에서 행 우측의 [🗑️ 삭제] 버튼을 누르면 해당 장비의 Supabase 전용 테이블(xrd_logs 등)에서 즉시 영구 삭제됩니다.

• 특별관리물질 취급일지 삭제: 관리대장 테이블 우측의 [🗑️ 삭제] 버튼으로 잘못 입력된 수불 내역을 정정할 수 있습니다.

📊 2. 연구실 안전 점검 대비 법정 서식 및 엑셀 출력

• 특별관리물질고지 추출: 재고 목록에서 원하는 물질을 체크박스로 선택 후 [특별관리물질고지]를 누르면 법정 고지문(관계자 외 출입금지)이 자동 생성되어 즉시 A4 인쇄/PDF 저장이 가능합니다.

• 산업안전보건법 제439조 특별관리물질 취급일지 서식: [특별관리물질취급일지]를 눌러 N센터 86291호 연구실 공인 서식의 엑셀 CSV를 즉시 내려받습니다.

☁️ 3. 장비별 독립 데이터베이스 테이블 관리 가이드

• 장비별 독립 테이블 (Table Editor): Supabase 콘솔에서 xrd_logs, tem_logs, afm_logs, wirebonder_logs, chemical_logs 등을 스프레드시트처럼 열어 대량 데이터를 직접 수정하거나 필터링할 수 있습니다.

• 통합 뷰 (view_equipment_sessions): 개별 테이블의 모든 데이터가 자동으로 UNION ALL 가상 뷰로 실시간 집계되어 웹앱 화면에 고속 렌더링됩니다.
